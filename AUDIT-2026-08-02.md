## 🔴 CRITICAL (5 — fix immediately)

### C1. Admin password `nyd2026` is bundled in the public JS
- **File:** `src/pages/AdminPage.js:8` + `.env:8`
- **Bug:** `const ADMIN_PASS = import.meta.env.VITE_ADMIN_PASSWORD || 'nyd2026';` — Vite inlines `VITE_*` vars at build time. The password is in `dist/assets/index-*.js`, readable by anyone via View Source.
- **Fix:** Server-side hash compare in a Supabase Edge Function. Never ship the password to the browser.

### C2. Admin "auth" is just a sessionStorage flag
- **File:** `src/pages/AdminPage.js:32, 339-360`
- **Bug:** `sessionStorage.getItem('admin_auth') === '1'` gates the dashboard. Setting it in devtools = instant admin. No server-side check.
- **Fix:** Real Supabase Auth (`signInWithPassword`) + gate RLS on `TO authenticated`.

### C3. `orders` table allows anonymous SELECT + UPDATE
- **File:** `supabase/migrations/003_create_orders_table.sql:48-53` + `20260617001_orders_anon_read_rls.sql:8-15`
- **Bug:** `FOR SELECT TO anon USING (true)` and `FOR UPDATE TO anon USING (true)` on `orders`. Anyone with the anon key can read every customer's name, address, phone, email, GST — and rewrite `status` (e.g. mark "delivered" without shipping), `address`, `payment_method`.
- **Fix:** `TO authenticated USING (auth.uid() IN (SELECT user_id FROM admins))` for SELECT/UPDATE; anon only for INSERT.

### C4. `send-order-email` Edge Function is an open mail relay
- **File:** `supabase/functions/send-order-email/index.ts:11, 15-19`
- **Bug:** Deployed with `--no-verify-jwt` and `Access-Control-Allow-Origin: *`. Any website can POST arbitrary HTML and send mail as `newyeardiaries@gmail.com` to any recipient — usable for brand phishing or Gmail quota spam.
- **Fix:** Verify JWT, add HMAC, or require `x-admin-token` header. Tighten CORS.

### C5. Enquiry tables (contact/quote) allow anonymous SELECT
- **File:** `supabase/migrations/007_fix_enquiry_rls_and_codes.sql:5-17` + `008_fix_submission_rls.sql:26-33`
- **Bug:** `FOR SELECT TO anon USING (true)` on `contact_submissions`, `quote_requests`, `enquiries`. Every B2B prospect's name, email, phone, project requirements world-readable.
- **Fix:** `TO authenticated`.

**Combined impact:** stranger can read all customer PII, become admin, mark orders shipped, send phishing as NYD's brand. Estimated 1 day to fix all 5 in one migration + auth flow PR.
